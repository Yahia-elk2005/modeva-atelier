
# Modeva Atelier - Luxury E-Commerce Platform 🕴️👗

Modeva Atelier is a premium, full-stack bespoke fashion e-commerce web application built using the **MERN** stack (MongoDB, Express.js, React.js, Node.js). It offers a seamless, high-end shopping experience with secure payment processing, real-time order tracking, and a comprehensive admin management system.

## ✨ Key Features

* **💳 Secure Payment Gateway (Stripe):** Fully integrated Stripe Checkout for processing credit/debit card transactions securely.
* **📦 Real-Time Order Tracking:** Interactive visual timeline in the Patron Dashboard to track order status (Confirmed ➔ Processing ➔ Dispatched ➔ Delivered).
* **📧 Automated Email Notifications:** Integrated `Nodemailer` to send branded HTML emails for OTP verification, order confirmations, and dispatch updates.
* **⭐ Dynamic Reviews & Ratings:** Users can leave comments and 1-5 star ratings, with the system automatically calculating the product's average rating.
* **🔍 Advanced Live Search & Filters:** Instant dynamic search and price range sliders to filter the catalog without page reloads.
* **🔐 Role-Based Access Control:** Secure JWT-based authentication distinguishing between regular Patrons and Admins.
* **🛠️ Admin Dashboard:** Complete CMS for managing products (CRUD), monitoring orders, updating shipping statuses, and generating promotional VIP vouchers.
* **📱 Fully Responsive UI:** Carefully crafted user interface using `React-Bootstrap` and custom CSS, ensuring a flawless experience across mobile, tablet, and desktop.

## 💻 Tech Stack

**Frontend:**
* React.js (v18+)
* React Router DOM (Navigation)
* React-Bootstrap & Bootstrap 5 (UI Framework)
* Swiper.js (Touch-friendly Carousels)
* React-Toastify (Notifications)
* Axios (HTTP Client)

**Backend:**
* Node.js & Express.js
* MongoDB & Mongoose (Database & ODM)
* JSON Web Token (JWT) & Bcrypt.js (Security & Auth)
* Stripe API (Payments)
* Nodemailer (SMTP Email Services)
